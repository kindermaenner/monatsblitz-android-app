# 1. Einführung und Ziele

Monatsblitz ist eine Android-Anwendung zur Verwaltung von Schachturnieren (Blitzschach). Sie ermöglicht die Auswahl von Spielern, die Wahl des Spielmodus und die Erfassung von Ergebnissen in einer Kreuztabelle.

### 1.1 Aufgabenstellung
*   Verwaltung von Spielern (lokal und via WordPress API).
*   Durchführung von Turnieren mit verschiedenen Modi (3+2, 5+0, Handicap).
*   Live-Berechnung von Ranglisten.
*   Synchronisation der Daten mit einer WordPress-Instanz.
